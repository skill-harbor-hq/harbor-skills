# Harbor Skills

Creator-owned [Muse](https://muse.ai) skills, hosted by
[Skill Harbor](https://theskillharbor.com) so their installers always
have a stable, inspectable source.

## Whose skills are these?

Every folder belongs to its creator — the Skill Harbor member named
by the folder. Skill Harbor hosts the files; it does not own them,
and hosting is not a review or an endorsement. Each folder carries
its creator's own LICENSE, which governs your use of that skill.
Always review a skill's files yourself before installing it.

## Structure

    <creator-slug>/<skill-slug>/SKILL.md   (plus reference files)

## Updates and removal

Creators can update their skill at any time through Skill Harbor:
new versions are staged, checked, and published here as new commits.
On a creator's request, Skill Harbor removes their folder from this
repository within 72 hours. Copies already downloaded, and the
public git history, cannot be recalled — that limit is stated up
front, before anything is hosted.

## Not this repo

Skills created by Skill Harbor itself live in
[house-skills](https://github.com/skill-harbor-hq/house-skills),
under the Skill Harbor House License.
