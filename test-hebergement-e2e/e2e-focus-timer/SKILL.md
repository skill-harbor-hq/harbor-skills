# E2E Focus Timer

A minimal focus timer for testing purposes.

## How it works

1. Start a focus session (default 25 minutes).
2. Work until the timer rings.
3. Take a short break (default 5 minutes).
4. Log each finished session in a local file.

See references/focus-tips.md for a few tips.
